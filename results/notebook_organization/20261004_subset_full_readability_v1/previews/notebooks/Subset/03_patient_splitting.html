Create patient-grouped folds: Subset data

We want to evaluate models on people whose images they have not seen during training. This notebook divides the training records into five repeatable groups, keeping each patient's images together and aiming for similar malignant-image percentages.

It follows 02_data_exploration.ipynb. The saved train_folds.csv lets later models use the same held-out patients, making their comparisons more useful. The reserved test stays separate.

Why group by patient?

Images from one person may share patient-specific details. If they appear in both training and evaluation, a model could benefit from that overlap. Each patient therefore belongs to one fold, one of five groups. Five-fold cross-validation trains on four groups and predicts the fifth, repeating until every image has a held-out prediction.

StratifiedGroupKFold is the splitting tool: it keeps patients together and tries to balance image labels. Exact balance may be impossible when whole patients move together. Seed 42 makes the assignment repeatable; we do not search seeds for a favourable score.

Set the paths and fold settings

Use the cleaned subset training file, five folds and seed 42. The code finds the project folder and names the saved table and figure. Later models should use this saved assignment rather than make a new split for each comparison.

Check that every patient stays in one fold

Both printed counts should be zero: no row should lack a fold, and no patient should appear in multiple folds. We also check that the image order and row count remain unchanged and that every fold contains both target classes. These checks prevent a balanced-looking chart from hiding an invalid assignment.

Save one shared fold file

Save the training rows with their fold assignments in data/subset/processed/train_folds.csv. If the existing file already matches, leave it as it is. The final checks confirm that the saved table keeps the same rows, order and targets.

Using this same file in later notebooks makes model comparisons easier to interpret: a score difference then cannot be explained by each model receiving a different split.

expected_columns = [*train.columns, "fold"]
saved_folds = (

Limitations

Keeping each patient in one fold prevents overlap through the supplied patient identifier. It cannot rule out related patients, incorrect identifiers, visually similar images from different identifiers, or differences between this dataset and future clinical data.

The split balances the image-level target approximately. It does not guarantee equal age, sex, site or patient-level positivity in every fold. Each held-out fold has only 25 or 26 malignant images, so performance measured later can vary considerably between folds.

Reusing these folds to develop models is useful, but repeatedly choosing methods from their scores can make the chosen model's development result optimistic. Freeze the final method before using the reserved test once. This notebook cannot establish model accuracy because it trains no model.

Summary

All 6,864 images from 422 patients receive one of five folds. Each fold has 1,370–1,381 images and 25 or 26 malignant images, giving malignant shares of 1.82–1.90%. No patient spans folds, no row is unassigned, and no patient overlaps with the reserved test in the saved checks.
