05a - Image uncertainty for the d1 subset: working experiment

This notebook checks how much the image model's scores change when it makes repeated predictions. Its purpose is to see whether that variation offers useful information about which images may need further review.

The question it answers is: do images with less stable predictions also tend to have larger prediction errors?

It follows 05_image_model_d1_wip.ipynb and loads that notebook's saved models and held-out predictions. It trains no new image model. It keeps two measurements separate: Monte Carlo dropout, which changes the active classifier units on each repeat, and test-time augmentation, which changes the image orientation. The later combined-model stage in 06_fusion_model_d1.ipynb may use these outputs after they have been checked across all folds.

Saved-run status

The saved execution covers fold 0: 1,370 held-out images from 84 patients, including 25 malignant images. Each image receives 30 Monte Carlo dropout predictions and eight fixed image views. These results remain a prototype check of one fold.

The ordinary prediction has AP 0.1415, the mean dropout prediction has AP 0.1471, and the mean across image views has AP 0.1414. These small differences alone do not establish that repeated prediction improves the model.

Referring the highest 20% by dropout variation removes 22.9% of the total absolute score error from the retained group. Both methods refer three of the 25 malignant images at that rate. This describes which images were set aside for review; the experiment does not observe what a reviewer would decide.

What the two measurements mean

Monte Carlo dropout, abbreviated MC dropout, repeatedly predicts the same image while randomly switching off some classifier units. The trained dropout rate stays at 20%. The mean is the average score over the repeats. The standard deviation, abbreviated SD, describes how far the scores tend to spread around that average. A larger SD means less stable predictions under this particular change.

Test-time augmentation, abbreviated TTA, predicts eight fixed flips and rotations with dropout switched off. Its SD describes sensitivity to image orientation. Its size is not directly comparable with dropout SD as a measure of total uncertainty because the two methods change different things.

The output names mean_probability and uncertainty_score refer to the MC mean and MC SD. The tta_probability_sd column stays separate. A high value may justify further investigation, but it does not establish that an image is malignant or that a prediction is wrong. A low value can occur when the model is consistently wrong.

The code labels scores between 0 and 1 as probabilities. The image model used class-weighted training and its current scores are poorly calibrated, so these values should not yet be read as a patient's melanoma risk.

Each image must be evaluated using the model for its held-out patient fold. During MC prediction, only the trained classifier dropout is active. BatchNorm, which stores feature statistics, stays in evaluation mode so those statistics remain fixed. Calibration fitting and any referral rule belong in a later training-only selection stage. The reserved test is not evaluated here.

Prediction controls

Step 4 - Define the three prediction modes

The ordinary mode uses the unchanged image with dropout switched off. MC mode uses that same image with only the trained dropout layer switched on. TTA mode uses the eight listed orientations with dropout off.

The code checks that MC mode leaves BatchNorm and the other layers in evaluation mode. This matters because changing their state would mix several effects into what is meant to be a dropout measurement.

class MelanomaDataset(Dataset):
    def __init__(self, dataframe, transform):
        self.dataframe = dataframe.reset_index(drop=True).copy()
        self.transform = transform

    def __len__(self):
        return len(self.dataframe)

    def __getitem__(self, index):
        row = self.dataframe.iloc[index]

        with Image.open(row["image_path"]) as source_image:
            image = source_image.convert("RGB")
            image = self.transform(image)

        return {
            "image": image,
            "image_id": row["image_name"],
        }


def build_model():
    model = efficientnet_b0(weights=None)
    number_of_inputs = model.classifier[1].in_features
    model.classifier[1] = nn.Linear(number_of_inputs, 1)
    return model.to(device)


def load_checkpoint(fold):
    path = checkpoint_path_for_fold(fold)
    checkpoint = torch.load(path, map_location=device, weights_only=True)

    expected_values = {
        "model_name": MODEL_NAME,
        "fold": int(fold),
        "image_size": int(IMAGE_SIZE),
        "epochs": int(NUMBER_OF_EPOCHS),
        "random_seed": int(RANDOM_SEED),
    }
    for field, expected_value in expected_values.items():
        if checkpoint.get(field) != expected_value:
            raise ValueError(
                f"Checkpoint {path} has {field}={checkpoint.get(field)!r}; "
                f"expected {expected_value!r}. Rerun the image-model notebook."
            )

    model = build_model()
    model.load_state_dict(checkpoint["model_state_dict"])
    model.eval()
    return model, checkpoint


def make_loader(dataframe, transform, seed):
    dataset = MelanomaDataset(dataframe, transform)
    generator = torch.Generator()
    generator.manual_seed(seed)

    return DataLoader(
        dataset,
        batch_size=BATCH_SIZE,
        shuffle=False,
        num_workers=0,
        pin_memory=torch.cuda.is_available(),
        generator=generator,
    )


def set_deterministic_mode(model):
    model.eval()
    active_modules = [
        name
        for name, module in model.named_modules()
        if name and module.training
    ]
    if active_modules:
        raise RuntimeError(
            "Deterministic mode left modules active: "
            + ", ".join(active_modules)
        )


def enable_mc_dropout(model):
    model.eval()
    dropout_modules = []

    for name, module in model.named_modules():
        if isinstance(module, nn.Dropout):
            module.train()
            dropout_modules.append({
                "name": name,
                "rate": float(module.p),
            })

    if not dropout_modules:
        raise RuntimeError("The model contains no Dropout module.")
    if any(
        not np.isclose(item["rate"], EXPECTED_DROPOUT_RATE)
        for item in dropout_modules
    ):
        raise RuntimeError(
            f"Expected trained dropout rate {EXPECTED_DROPOUT_RATE}; "
            f"found {dropout_modules}."
        )

    active_non_dropout = [
        name
        for name, module in model.named_modules()
        if (
            name
            and module.training
            and not isinstance(module, nn.Dropout)
        )
    ]
    active_batchnorm = [
        name
        for name, module in model.named_modules()
        if (
            isinstance(module, nn.modules.batchnorm._BatchNorm)
            and module.training
        )
    ]
    if active_non_dropout or active_batchnorm:
        raise RuntimeError(
            "MC mode activated non-Dropout modules. "
            f"Other active: {active_non_dropout}; "
            f"BatchNorm active: {active_batchnorm}."
        )

    return dropout_modules


def predict_probabilities(model, loader):
    image_ids = []
    probabilities = []

    with torch.no_grad():
        for batch in loader:
            images = batch["image"].to(device, non_blocking=True)
            logits = model(images).squeeze(1)
            batch_probabilities = torch.sigmoid(logits).cpu().numpy()

            image_ids.extend(batch["image_id"])
            probabilities.extend(batch_probabilities.astype(float))

    return image_ids, np.asarray(probabilities, dtype=float)

Step 8 - Read the prediction-quality table

This table compares the ordinary score, the mean dropout score, and the mean across image views on the same held-out images. It tests the average predictions, rather than how well SD identifies mistakes.

Average precision, or AP, asks how effectively malignant images rise to the top of the ranking across score cutoffs. Higher is better. ROC-AUC is another ranking measure, with 0.5 as a chance-level reference. Neither number is the percentage of images classified correctly. Log loss and Brier score compare the score with the known label; lower is better. Mean absolute error is also lower when scores are closer to labels, but the many benign images have a large influence on it.

The saved dropout mean has AP 0.1471 versus 0.1415 for the ordinary score. Its Brier score is slightly worse, 0.2296 versus 0.2294. A small ranking improvement can therefore coexist with poor score calibration. This one-fold comparison has no interval for the difference.

def binary_probability_metrics(targets, probabilities):
    targets = np.asarray(targets, dtype=float)
    probabilities = np.asarray(probabilities, dtype=float)

    if not np.isfinite(probabilities).all():
        raise ValueError("Probabilities contain non-finite values.")
    if ((probabilities < 0) | (probabilities > 1)).any():
        raise ValueError("Probabilities must lie between zero and one.")

    has_both_classes = np.unique(targets).size == 2
    has_positive = np.sum(targets) > 0

    return {
        "roc_auc": (
            float(roc_auc_score(targets, probabilities))
            if has_both_classes
            else np.nan
        ),
        "average_precision": (
            float(average_precision_score(targets, probabilities))
            if has_positive
            else np.nan
        ),
        "log_loss": float(
            log_loss(targets, probabilities, labels=[0, 1])
        ),
        "brier_score": float(
            brier_score_loss(targets, probabilities)
        ),
        "mean_absolute_probability_error": float(
            np.mean(np.abs(targets - probabilities))
        ),
    }

Step 11 - Read the referral table and risk-coverage figure

For each method, the code sorts images from highest to lowest variation and sets aside a fixed fraction for review. Both rankings use the same MC mean score to measure prediction error. This makes the comparison about which images are set aside.

In the table, referral_rate is the fraction set aside and coverage is the fraction still handled by the model. referred_absolute_error_share is the share of total score error in the set-aside images. referred_malignant_share is the share of malignant images set aside. def risk_coverage_table(
    predictions,
    score_column,
    uncertainty_method,
    referral_rates,
):
    ordered = predictions.copy()
    ordered["absolute_probability_error"] = np.abs(
        ordered["target"] - ordered["mean_probability"]
    )
    ordered = ordered.sort_values(
        [score_column, "image_id"],
        ascending=[False, True],
        kind="mergesort",
    ).reset_index(drop=True)

    total_absolute_error = ordered[
        "absolute_probability_error"
    ].sum()
    total_malignant = ordered["target"].sum()
    rows = []

    for referral_rate in referral_rates:
        number_referred = int(
            np.ceil(len(ordered) * referral_rate)
        )
        referred = ordered.iloc[:number_referred]
        retained = ordered.iloc[number_referred:]

        if retained.empty or retained["target"].nunique() < 2:
            continue

        metrics = binary_probability_metrics(
            retained["target"],
            retained["mean_probability"],
        )
        referred_error_share = (
            referred["absolute_probability_error"].sum()
            / total_absolute_error
            if total_absolute_error > 0
            else 0.0
        )
        referred_malignant_share = (
            referred["target"].sum() / total_malignant
            if total_malignant > 0
            else 0.0
        )

        rows.append({
            "uncertainty_method": uncertainty_method,
            "score_column": score_column,
            "prediction_column": "mean_probability",
            "referral_rate": float(referral_rate),
            "coverage": len(retained) / len(ordered),
            "referred_images": int(len(referred)),
            "retained_images": int(len(retained)),
            "referred_malignant_images": int(
                referred["target"].sum()
            ),
            "retained_malignant_images": int(
                retained["target"].sum()
            ),
            "referred_absolute_error_share": float(
                referred_error_share
            ),
            "referred_malignant_share": float(
                referred_malignant_share
            ),
            **metrics,
        })

    return pd.DataFrame(rows)

Limitations

The saved run covers one fold, 84 patients, and 25 malignant images. It cannot establish that either uncertainty method works consistently across patients, select a clinical referral rule, or show final performance. The small AP differences and error associations have no patient-based confidence intervals.

MC dropout changes only the trained classifier dropout layer. Its SD measures one limited source of variation; it does not capture all uncertainty in the image features, data, labels, or separately trained models. TTA measures sensitivity to the eight chosen orientations. A stable prediction can still be wrong, and larger SD has not been validated as an individual risk estimate.

The underlying model used class-weighted training and has poorly calibrated scores. Absolute score error is dominated by benign images and can track the score itself. Without comparisons against random referral, score-based referral, and other simple rankings, the curves cannot establish that SD adds useful information beyond the score. Lower retained-group error also leaves referred outcomes unmeasured and changes the case mix.

The 30-repeat convergence check uses the 30-repeat estimate as its own reference. It cannot establish convergence beyond that run. The reliability plot has few malignant cases and no intervals. No correction or referral threshold is selected here; any later selection needs training-only patient groups and a separate evaluation.

The current model-loading checks record only some settings and do not identify the exact training data or complete recipe. The repeated-prediction checks confirm a matching handoff, but cannot reconstruct training provenance. Summary checks also need stronger validation of every raw repeat to reject missing or duplicate repeats before aggregation. The present saved results are descriptive development evidence, and the reserved test is not evaluated here.

Summary

The saved prototype reproduces the image-model handoff and produces variation under both repeated dropout and image orientation changes. The dropout mean has AP 0.1471, compared with 0.1415 for the ordinary score and 0.1414 for the TTA mean. Dropout SD has a stronger association with absolute score error on this fold, but the current scores overstate melanoma risk.

Keep MC dropout as a candidate uncertainty method and retain TTA as a separate orientation-sensitivity check. Neither is ready to support a clinical referral rule. At 20% referral, both methods set aside three of the 25 malignant images, and the experiment does not observe their review outcomes.

Next, resolve the image-model and provenance limitations, complete all five held-out folds, and repeat these checks with patient-based intervals and simple referral baselines. Choose any calibration or referral rule using training patients before evaluating it on held-out patients. Use the reserved test once after the whole workflow has been fixed.
